# F1 Geovisual Atlas

Интерактивный географический атлас Formula 1 для выпускной квалификационной работы по направлению «Картография и геоинформатика».

## Концепция

Центральная задача проекта — показать, как менялась география чемпионата Formula 1 с 1950 года. Пользователь сможет выбрать сезон, увидеть входившие в календарь трассы, последовательность этапов и подробную историю выбранного автодрома.

Проект планируется как образовательное неофициальное приложение для любителей автоспорта. Оно не связано с Formula 1, FIA или командами чемпионата.

## Планируемые возможности

- интерактивный глобус с трассами и маршрутами выбранного сезона;
- временная шкала 1950–2026;
- карточки трасс с геометрией, характеристиками, фактами и историей;
- календарь, результаты и положение участников в выбранном сезоне;
- программно построенные 3D-трассы;
- хронология ключевых событий;
- отдельный экспериментальный режим анализа телеметрии.

## Структура репозитория

```text
.
├── apps/
│   └── web/                 # основное приложение Next.js
├── data/                    # правила подготовки и хранения данных
├── database/                # миграции PostgreSQL/PostGIS
├── docs/                    # концепция и проектные решения
└── F1_v1/
    └── F1_v1/               # сохранённый исследовательский прототип
```

`F1_v1/Delta-main` используется только как локальный сторонний референс по телеметрии и 3D-визуализации. Он намеренно исключён из Git: внутри находятся чужой исходный код, виртуальное окружение, зависимости и кэши. Если отдельные идеи будут перенесены, они должны быть реализованы как собственный модуль с проверенной лицензией и атрибуцией.

## Текущее состояние

Рабочий интерфейс атласа построен на React и стандартном Next.js App Router и
использует подготовленные JSON/GeoJSON. PostgreSQL/PostGIS является основным хранилищем сезонов с
1950 года, исторических конфигураций трасс, результатов, туристических объектов
и 3D-зданий. Старый прототип сохранён как источник данных и идей, но не
рассматривается как архитектурная основа новой версии.

Целевая инфраструктура публикации — Vercel для приложения и Supabase для
управляемой PostgreSQL/PostGIS. На первом этапе сайт продолжает публиковать
проверенные снимки данных, поэтому публичные страницы не зависят от доступности
базы при каждом просмотре.

Архитектура базы описана в `database/README.md`, а порядок загрузки и обновления
данных — в `docs/import-pipeline.md`. Порядок подготовки облачных окружений и
публикации описан в `docs/deployment.md`.

## Локальный запуск веб-приложения

```powershell
cd apps/web
pnpm install
pnpm dev
```

Проверка production-сборки:

```powershell
pnpm build
pnpm start
```

## Источники и лицензирование

Перед публикацией необходимо отдельно зафиксировать происхождение каждого набора данных, картографической подложки, изображения, видео и 3D-модели. Материалы телевизионных трансляций используются только как визуальные референсы и не включаются в репозиторий.

Лицензия собственного кода проекта будет выбрана до публичной публикации.
