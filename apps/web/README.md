# Web application

Здесь будет находиться основное веб-приложение проекта.

Планируемый стек:

- React;
- TypeScript;
- Vite;
- MapLibre GL JS;
- Three.js для отдельных 3D-представлений;
- тестирование преобразований геоданных и основных пользовательских сценариев.

Приложение будет создано отдельным шагом после фиксации исходного состояния репозитория.
