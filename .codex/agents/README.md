# Агенты проекта

Проект использует одиннадцать узких конфигураций Codex:

- `code_mapper` — карта кода и потоков данных без изменений
- `browser_debugger` — воспроизведение интерфейсных и картографических ошибок
- `ui_designer` — спецификация композиции и взаимодействий без изменений
- `frontend_developer` — крупные изменения React, TypeScript, CSS и MapLibre
- `ui_fixer` — небольшие локальные исправления интерфейса
- `data_engineer` — GeoJSON, сезоны, конфигурации, маршруты и импорт данных
- `postgres_pro` — PostgreSQL/PostGIS, миграции и пространственные запросы
- `reviewer` — итоговая проверка без изменений
- `f1_history_researcher` — доказательная история Formula 1 и конфигураций трасс
- `travel_curator` — редакционный отбор туристических объектов и маршрутов
- `media_rights_specialist` — источники медиаматериалов, лицензии и реестр прав

Все проектные агенты используют `gpt-5.6-sol` с `model_reasoning_effort = "medium"`.

## Правила работы

- Для одной группы файлов назначается только один агент с правом записи
- Параллельно безопасно запускать исследование, браузерную диагностику и ревью
- Агенты не создают коммиты без прямого запроса
- Существующие изменения пользователя не перезаписываются
- Результат каждого агента возвращается основному агенту в виде краткого отчёта
