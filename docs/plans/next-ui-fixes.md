- В разделе истории удалены оставшиеся формулировки о «редакционном каркасе» и обещания неподтверждённых материалов. Пустые разделы явно обозначены как неопубликованные до проверки источников и прав; новые исторические факты не добавлялись.
- Открыто: проверка шапки на 90%; общий проход по пунктам 3, 5, 6 и 11. Проверку аналитического счётчика выбранных пилотов пропускаем по просьбе пользователя. Перенос «Схемы сезона» по-прежнему отложен.
- Во вступлении атласа субъективное «легендарные трассы» заменено на конкретное описание интерактивной карты и географии календаря; структуру первого экрана и данные не меняли. Пункт 5 остаётся открытым для остальных текстов.
- После сообщения пользователя о пропавшей навигации для 981–1500 CSS px добавлена двухстрочная шапка: ссылки остаются видимыми без конкуренции с поиском за одну строку.
