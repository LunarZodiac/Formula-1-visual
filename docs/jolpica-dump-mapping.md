# Сопоставление CSV-выгрузки Jolpica

Публичную атрибуцию добавим перед публикацией проекта. Внутри конвейера источник,
дата выгрузки и контрольная сумма сохраняются сразу, чтобы происхождение данных
не потерялось.

## Первая очередь импорта

| CSV Jolpica | Таблица атласа | Назначение |
| --- | --- | --- |
| `formula_one_season` | `seasons` | сезоны 1950–2026 |
| `formula_one_circuit` | `circuits` | точки и справочник трасс |
| `formula_one_driver` | `drivers` | пилоты |
| `formula_one_team` | `constructors` | команды |
| `formula_one_teamdriver` | `constructor_entries` | составы по сезонам |
| `formula_one_round` | `races` | этапы календаря |
| `formula_one_session` | `sessions` | гонки, квалификации, спринты и практики |
| `formula_one_sessionentry` | `session_results` | классификации сессий |
| `formula_one_*championship` | `*_standings` | положения в зачётах |

Квалификационные сегменты `Q1/Q2/Q3` и `SQ1/SQ2/SQ3` будут объединены в одну
сессию этапа, а их времена сохранятся в `details`.

## Вторая очередь

- `formula_one_lap` — 720 тысяч кругов;
- `formula_one_pitstop` — пит-стопы;
- `formula_one_penalty` — штрафы;
- системы начисления очков и корректировки чемпионата.

Эти таблицы не нужны для первого отображения сезонов и значительно увеличивают
объём. Для них будет отдельная миграция и отдельный импорт, чтобы основной сайт
не загружал телеметрический слой без необходимости.
