# Задача: краткое название

## Результат

Одно проверяемое предложение о том, что должно заработать или измениться

## Критерии готовности

- наблюдаемое поведение или итоговые данные
- состояние ошибки, пустых данных или узкого экрана, если применимо
- конкретная проверка, достаточная для риска изменения

## Контекст

- обязательные документы: перечислить только нужные
- исходные файлы и символы: перечислить известные
- подтверждённые факты: перечислить без пересказа истории проекта

## Область записи

- файлы или каталог, которыми владеет исполнитель

## Не изменять

- соседние подсистемы и данные вне задачи

## Профиль выполнения

- агент: основной агент или одна специализированная роль
- модель: `gpt-5.6-luna`, `gpt-5.6-sol` или `gpt-6-astra`
- усилие: `low`, `medium` или `high`
- причина повышения усилия: заполняется только для `high`

## Отчёт

- результат
- изменённые файлы
- выполненная проверка
- остаточный риск или блокер
