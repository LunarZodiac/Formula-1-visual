# Формат передачи векторов трасс

## Предпочтительный формат

Предпочтительно передать **один общий файл GeoJSON** со всеми готовыми
конфигурациями. Каждая отдельная конфигурация — самостоятельный объект
`Feature` внутри массива `features`. Делить пакет на десятки файлов не нужно

Для ручной оцифровки подготовлен рабочий слой
`data/templates/f1-track-digitizing-worklist.geojson`. В нём уже заполнены
идентификаторы, названия, периоды и ожидаемая длина. Маленькую
линию-заглушку каждого объекта нужно заменить полным контуром;
атрибуты менять не нужно

- система координат: WGS 84 / EPSG:4326
- геометрия: `LineString` по центральной линии трассы
- порядок координат: `[долгота, широта]`
- линия замкнута: первая и последняя точки совпадают
- направление точек совпадает с направлением движения
- рекомендуемая детализация: 100–1500 точек без дрожания и дубликатов
- кодировка: UTF-8

Рекомендуемое имя общего файла:

```text
f1-track-configurations.geojson
```

Если удобнее передавать трассы частями, допустимы несколько файлов вида
`f1-track-configurations-part-01.geojson`. Формат объектов внутри остаётся тем
же

Перед передачей весь пакет можно проверить командой:

```powershell
node scripts/validate-track-geometry-batch.mjs f1-track-configurations.geojson
```

## Обязательные свойства объекта

| Поле | Тип | Пример |
|---|---|---|
| `id` | строка | `be-spa-1950-road` |
| `circuitId` | строка | `spa` |
| `name` | строка | `Circuit de Spa-Francorchamps` |
| `nameRu` | строка | `Спа-Франкоршам` |
| `configuration` | строка | `Old road circuit` |
| `fromSeason` | число | `1950` |
| `toSeason` | число | `1970` |
| `eventIds` | массив строк | `[]` или `["2020-16"]` |
| `length` | число, метры | `14100` |
| `direction` | строка | `clockwise` или `counterclockwise` |
| `source` | строка | название источника |
| `sourceUrl` | строка | ссылка на исходную карту или данные |
| `license` | строка | `ODbL-1.0`, `CC-BY-4.0`, `Public domain` |
| `checkedAt` | дата | `2026-08-26` |

`eventIds` оставляем пустым, если конфигурация относится ко всем этапам
указанных сезонов. Поле обязательно заполняется, если в одном сезоне на одном
автодроме использовались разные конфигурации, как в Бахрейне в 2020 году.

Полезные необязательные поля: `startFinish: [longitude, latitude]`,
`countryCode`, `location`, `notes`.

## Допустимые альтернативы

- KML, GPX или Shapefile можно передать вместе с таблицей свойств, но перед
  импортом они будут преобразованы в GeoJSON
- SVG допустим только с географической привязкой: минимум три контрольные точки
  с долготой и широтой либо точная рамка `west, south, east, north`
- PNG/JPEG подходит как источник для ручной отрисовки, если указаны сезон,
  конфигурация, масштаб или привязка и лицензия
- DXF без географических координат нежелателен: его придётся отдельно совмещать
  с картой

Нельзя использовать вектор с неизвестным происхождением или без права на
публикацию. Лучше всего подходят собственная отрисовка по разрешённому
источнику, OpenStreetMap/ODbL, открытые государственные данные, CC BY, CC BY-SA
или public domain.
