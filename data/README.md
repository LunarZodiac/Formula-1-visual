# Data workspace

Каталог предназначен для подготовленных данных новой версии приложения.

Исходные CSV, GeoJSON и XLSX пока остаются внутри сохранённого прототипа `F1_v1/F1_v1`. Они будут переноситься сюда только после проверки идентификаторов, происхождения, лицензий, полноты и системы координат.

Планируемая структура:

```text
data/
├── raw/         # исходные данные без ручного редактирования
├── processed/   # нормализованные данные приложения
└── sources/     # описание источников и лицензий
```
